## Golden query `golden-v1`

The engine runs `SELECT value FROM read_om(<fixture>) ORDER BY value ASC NULLS FIRST LIMIT 64`. Each selected `FLOAT` is hashed as a one-byte tag followed by its IEEE-754 float32 bits in big-endian order (`0x00` for null; `0x01 || value_bits` otherwise). This avoids relying on text formatting. The independent official OM C API reader exported this fixture's full root array for comparison; `scripts/hash-golden-oracle.py` derives the expected hash from that CSV. Each platform lock entry stores the independently derived hash only after a bootstrap run verifies DuckDB version, platform, extension version, required functions, and agreement with the oracle.

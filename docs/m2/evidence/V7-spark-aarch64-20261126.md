## Invariant Verification Details

### 1. Cancel (`map_load_field`)
- In each trial, a field load was dispatched against the regional East Asia station bounding box.
- As soon as the worker reported progress stage `"reading"`, an interrupt was sent for the target request ID.
- In all 10 trials, the request terminated with `failed` containing cancellation detail, and the worker immediately answered subsequent requests (`catalog_check` returned `state: "ready"`).

### 2. Worker Crash & Generation Reaping (`kill9` at Load & Render)
- Before the kill point, a seed render placed tiles into the generation directory `results/g1/` (`8` files before kill).
- When the kill was triggered (at `load` during data reading or at `render` during a 96-tile batch), the supervisor caught `WorkerCrashed`.
- The supervisor incremented the generation counter `g1 → g2` and invoked `reap_generation_dir()` on the crashed generation.
- Verified in all 20 trials:
  - `leaked_old_generation_files: 0` (the crashed generation directory was completely purged);
  - A follow-up tile render request dispatched to the new worker generation `g2` succeeded immediately;
  - On clean shutdown, `files_after_shutdown: 0`.

### 3. Offline Isolation (`offline`)
- Worker processes were bootstrapped with `no_network = true` in an isolated directory.
- `map_load_field` failed with `CapabilityUnavailable(remote)` without hanging or crashing.
- `map_render_tiles` for `fixtures/pmtiles/sample-raster.pmtiles` completed successfully with valid tile outputs and empty `layer_errors`.

### 4. Atomic Composite Export Boundary (`export-kill`)
- `omo-harness export-kill --source map --at step1|step2|step3` was run for 10 trials per step.
- Step 1 (killed before target rename): recovered `incomplete`, `saved=false`.
- Step 2 (killed after target rename, before sidecar rename): recovered `incomplete`, `saved=false` (no partial/unprovenanced exports recognized).
- Step 3 (killed after sidecar commit + directory fsync): recovered `finished`, `saved=true`.

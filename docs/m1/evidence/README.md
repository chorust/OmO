# M1 Evidence Conventions

Every evidence record under `docs/m1/evidence/` records:
- Host and target triple (e.g., `lizhan-spark`, `aarch64-unknown-linux-gnu`);
- Date (UTC);
- Locked software versions (`rustc 1.100.0`, `DuckDB v2.0.0`, `duckomo v0.4.0`, `NSH 0.5.1`);
- Exact command executed;
- Observed result and output artifact paths.

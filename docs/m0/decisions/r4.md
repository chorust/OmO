# R4: spatial provisioning before configuration lock

On Spark Linux arm64, both locked artifact channels now pass the current `omo-probe --r4` path on fresh caches. The report records `spatial_preinstall: ok` and `spatial_after_lock: ok`; `LOAD spatial` therefore succeeds after configuration lock because provisioning occurred first.

- `community-signed`: bootstrap and golden query pass; HTTPFS and spatial install; built-in community and unsigned loading are disabled from connection open; repository access is forbidden after Duckomo loads. The unsigned close is not applicable.
- `github-release-unsigned`: bootstrap and golden query pass; HTTPFS and spatial install; spatial loads after lock; the temporary unsigned window closes with `allow_unsigned_extensions=false`; custom repository access is forbidden before Duckomo loads.
- Both reports match the locked 64-row golden SHA-256 `bc7cf6db243073d9baee64cdda6900cae9547a33bde00f61b8da10a7ce30254f`.

The selected worker mitigation is to provision the signed spatial artifact before locking configuration, then load it after lock when a task needs region/map work. A local-only worker may leave it uninstalled; if the artifact is unavailable, report the spatial capability as unavailable. The worker must not enable a different channel or retry unsigned after a signed-route failure.

The current reports are [community-signed](../evidence/EXIT-1-spark-aarch64-community-r4-hardened-final-20261120.json) and [GitHub-release-unsigned](../evidence/EXIT-1-spark-aarch64-unsigned-r4-hardened-final-20261120.json), with the combined [R4 evidence note](../evidence/SPIKE-4-current-r4-spark-aarch64-20261120.md). A separate signed `bwrap --unshare-net` run passed the local golden query and rejected a remote task with `CapabilityUnavailable(remote)`; see [network-isolation evidence](../evidence/COMMUNITY-LOCAL-NETWORK-ISOLATION-spark-aarch64-20261120.md).

This evidence applies to Spark Linux arm64. Linux x86_64 and macOS arm64 runs remain `not-run`; the global artifact-channel decision remains open until each target has evidence.

# T039 harness implementation and runtime verification — 2026-11-17

The `omo-harness` binary provides:

- `gen-result --rows N --cols N [--output PATH]` for deterministic, batch-wise Arrow IPC fixtures (up to 10,000,000 rows and 256 columns).
- `gen-result --series N --points N [--output PATH]` for numeric plot fixtures.
- `progress --hz N --minutes N` for paced newline-delimited progress events.
- `crash-inject --iterations N` for deterministic worker crash/restart through `EngineSupervisor`.
- `cancel --levels 1,2,3` for fake-worker interrupt acknowledgment and host drain/kill state-machine outcomes.
- `export-kill --at step1|step2|step3` for export commit fault injection; this command requires `in-process-engine`.

## Verification

- Toolchain: Rust `1.100.0`.
- `RUSTUP_TOOLCHAIN=1.100.0 cargo run --locked -p omo-app --no-default-features --features in-process-engine --bin omo-harness -- crash-inject --iterations 20` passed: 20 recoveries, generation 1 → 21. Full JSON is in [EXIT-4 crash output](EXIT-4-spark-aarch64-n-a-20261117-crash.json).
- `RUSTUP_TOOLCHAIN=1.100.0 target/debug/omo-harness cancel --levels 1,2,3` passed. Level 1 was acknowledged by the fake worker; levels 2 and 3 exercised drain completion and kill escalation in the host state machine. Full JSON is in [EXIT-4 cancellation output](EXIT-4-spark-aarch64-n-a-20261117-cancel.json).
- `gen-result` produced the retained N2/N3 fixture files under `/tmp/omo-accept`; their dimensions and hashes are recorded in [N2](N2-spark-aarch64-x11-20261117.md) and [N3](N3-spark-aarch64-x11-20261117.md).
- The 10-minute progress harness mode is implemented. The N7 UI workload used the live worker progress stream at 50 Hz; evidence is in [N7](N7-spark-aarch64-x11-20261117.md).

## Limits

The harness's cancellation levels 2 and 3 are state-machine simulations, not measurements of a real worker's drain timing. The live worker interrupt, kill/restart, and UI recovery are reported separately in T034 and N7. Cross-platform harness runs remain unavailable without Linux x86_64 and macOS arm64 hosts.

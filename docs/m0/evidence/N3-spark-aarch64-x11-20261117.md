## Visible-render timing and measured M0 cap

The additional timing run used an isolated Xvfb-backed X11 session on lizhan-spark (`DISPLAY=:101`, 1600×1000 root, 1440×960 app window). It used the release binary SHA-256 `508062f63348612804140e924a25253fa92f8ece93cde7fc05d115698934df8e` and the same 10,000-row × 20-numeric-column Arrow fixture recorded above. The fixture was loaded before the timing trials, so this measures selecting the Plot tab through visible chart content; it excludes query execution and worker result preparation.

For each trial, the pointer was moved to the Plot tab before timing. The click-only command used `xdotool click --delay 0 1`; the screen was sampled with `PIL.ImageGrab` over `(500,237)-(801,433)`. The dark SQL view had RGB `(23,28,25)` at both the grid probe `(500,237)` and the series probe `(800,432)`. A visible plot sample had grid RGB `(228,225,216)` and series RGB `(121,116,108)`. The series probe therefore detects a plotted data path, not only the chart background. Each trial recorded the last dark capture and first visible capture. The lower bound is last-dark capture start minus click-command return; the upper bound is first-visible capture end minus click-command start. The resulting interval includes input and capture overhead. The gap from the last dark capture end to the first visible capture start was 2.26–8.25 ms.

| Trial | Click command (ms) | Conservative interval (ms) | Observation gap (ms) |
|---:|---:|---:|---:|
| 1 | 9.14 | 199.72–259.16 | 8.25 |
| 2 | 5.04 | 213.91–236.43 | 2.47 |
| 3 | 8.00 | 191.59–240.84 | 7.42 |

The median per-trial upper bound was 259.16 ms; the maximum was 281.08 ms. These are conservative bounds for Plot-tab activation to first visible grid and series pixels on this Xvfb X11 session, not an application-only render duration or a tail-latency guarantee.

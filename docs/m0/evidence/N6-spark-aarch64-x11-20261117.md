## Limits

`OMOBENCH_BOOTSTRAP_CONFIG` was unset in these UI sessions, so the app reported engine bootstrap failure; the SQL editor remained available and was the surface tested. The IBus app log included a `Type 'h' is not supported` warning while typing, but the IBus candidate selection, commit, and copied text were directly verified.

The complete Linux Wayland cell remains not-run; a partial nested Weston Fcitx attempt is recorded in [Wayland evidence](N6-spark-aarch64-wayland-20261117.md), but its Fcitx log contained a Wayland input-panel error and IBus candidate selection was not established. Linux x86_64 Wayland/X11 and macOS system Pinyin cases remain not-run. This evidence does not establish full N6 matrix coverage.

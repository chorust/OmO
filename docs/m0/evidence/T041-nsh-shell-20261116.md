# T041 NSH shell implementation and compile verification — 2026-11-17

## Implemented shell

- `omo-app` pins NSH 0.5.1 with `default-features = false` and the `editor`, `highlight`, and `plot` platform features; no QuickJS feature is enabled.
- The Linux and macOS entry points use `AppSource::Rust` and `run_app` with app id `com.omobench.studio`.
- `ui/workspace.rs` composes Sources, SQL, Results, Plot, and Tasks in a `DockArea`; File/View menus and run/cancel shortcuts are present.
- SQL edits update a document revision. Preview requests are coalesced by `PreviewQueue`, dispatched through the runtime bridge, and published only after revision and worker-generation checks.
- The result table reads visible IPC pages. Omobench explicitly marks result columns sortable; a post-fix sort-header action on isolated X11 advanced the request count from 1 to 2 and changed displayed rows from `3, 1, 2` to `1, 2, 3` (full record: [N2](N2-spark-aarch64-x11-20261117.md)).
- The plot samples numeric values from the full IPC result and enforces the measured 20-series × 10,000-point cap; the chart label reports the sampling cap.
- The Tasks panel reports worker state and the bootstrap report, exposes cancellation/retry, and routes current-generation results to CSV/Parquet export. File pickers have manual path fallback and overwrite confirmation.
